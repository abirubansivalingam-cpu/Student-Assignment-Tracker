# Student Assignment Tracker

## Project Overview

Student Assignment Tracker is a web-based application developed using Python and Django to help students manage their academic assignments efficiently.

## Features

- Student Registration and Login
- User Profile Management
- Add New Assignments
- Update Assignments
- Delete Assignments
- Track Assignment Due Dates
- Set Assignment Priorities
- Mark Assignments as Completed
- Dashboard for Assignment Management
- PostgreSQL Database Support

## Technology Stack

- Frontend: HTML, CSS, JavaScript
- Backend: Python, Django
- Database: PostgreSQL
- Version Control: Git and GitHub

## Installation

1. Clone the repository.
2. Create and activate a Python virtual environment.
3. Install dependencies.
4. Configure the database.
5. Run migrations.
6. Start the Django development server.

## Run the Project

```bash
python manage.py migrate
python manage.py runserver
```
